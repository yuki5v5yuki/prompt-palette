Prompt Palette Manual

Prompt Palette

よく使う文章を登録して、必要な場所で一瞬で呼び出すためのアプリです。 まずは「作る → 呼ぶ → 貼る」の3つだけ覚えればOKです。

使い方の流れ

まず、何ができるアプリ？

Prompt Palette は「毎回書いている文章」を保存して、必要なときにすぐ出す道具です。 AIへの指示、メール返信、日報、問い合わせ対応など、くり返し使う文章に向いています。

テンプレート

よく使う文章を名前つきで保存します。

ランチャー

Ctrl + Space で小さな検索画面を出します。

入力欄

名前、日付、商品名など、毎回変わる部分だけ入力できます。

タグ

文章を探しやすくするラベルです。

引っ越し

インポート/エクスポートでバックアップや共有ができます。

管理画面でテンプレートを作る

ここは「準備する場所」です。まずは文章の名前と本文だけを登録します。 ランチャーを使う場面とは分けて考えます。

管理画面でやること

まずは1つだけ作れば大丈夫です。名前を付けて、本文を書いて、保存します。

  1. 左メニューの テンプレート を開く
  2. 新規テンプレート を押す
  3. タイトルに「問い合わせ返信」など探しやすい名前を書く
  4. 本文に、呼び出したい文章を書く
  5. 保存 を押して登録する

ランチャーで呼び出して貼る

ここは「実際に使う場所」です。メモ、メール、ブラウザなど、文章を入れたい場所を開いたままランチャーを呼び出します。 管理画面とは別の場面です。

ランチャーでやること

入力したい場所を先に開いてから、ランチャーを呼び出します。今回はシンプルに、選んだ文章をそのまま貼ります。

  1. テキストメモなど、貼り付けたい場所を開く
  2. Ctrl + Space でランチャーを出す
  3. 検索欄に「問い合わせ」と入れる
  4. 問い合わせ返信 を選ぶ
  5. Enterで確定して、今の場所へ貼り付ける

入力欄は、毎回変わる部分に使う

名前や日付など、毎回変わるところだけ入力欄にします。返信トーンのように、候補から選びたい部分にも使えます。

毎回変わる部分 お客様名、商品名、日付、担当者名、URL、今日の作業内容
選択式にしたい部分 返信トーン、優先度、カテゴリ、決まった言い回し
本文に残す部分 毎回同じあいさつ、説明、締めの文章

困ったとき

まずは下の対処だけ試してください。原因を細かく調べるより、すぐ使える状態に戻すことを優先します。

Ctrl + Space で出ない

アプリが起動しているか確認します。出ない場合は設定で別のショートカットに変えてみます。

検索しても見つからない

カテゴリを「すべて」に戻します。タグやタイトルに別の言葉を入れて探します。

入力欄が出ない

テンプレート本文に入力欄が入っているか確認します。本文内のチップが目印です。

自動で貼り付かない

文章はクリップボードにコピー済みです。手動で Ctrl + V を押してください。

おすすめの使い方

AIへの指示 「この文章をやさしく直して」「要点だけまとめて」など、よく使う頼み方を保存します。
メール返信 問い合わせ返信、日程調整、受領連絡などを入力欄つきで作れます。
日報・メモ 今日やったこと、困ったこと、明日やることの型を作れます。
SNS下書き 投稿の型、告知文、コメント返信のたたき台をすぐ呼び出せます。
